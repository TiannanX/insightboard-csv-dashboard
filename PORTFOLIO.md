# InsightBoard CSV Dashboard — Portfolio Case Study

## Problem

Small businesses, students, and freelance clients often have useful CSV data but no quick way to turn it into a clear dashboard without uploading files to a third-party service or setting up a backend.

## Solution

InsightBoard is a local-first React dashboard starter. Users upload a sales-style CSV or load demo data, then get KPI cards, charts, local rule-based insights, a searchable data table, and a Markdown export.

## Key Features

- Drag-and-drop CSV upload with local Papa Parse processing.
- Required schema validation with clear errors and skipped-row warnings.
- KPI cards for revenue, cost, profit, margin, units, and records.
- Recharts visualizations for revenue trends, category revenue, regional profit, and top products.
- Searchable and sortable data explorer.
- Rule-based insights calculated in the browser.
- Markdown dashboard summary export.

## Tech Stack

- React 19
- Vite
- Papa Parse
- Recharts
- CSS Modules

## What This Demo Proves

For freelance clients, this project demonstrates the ability to:

- Turn messy spreadsheet workflows into a polished browser experience.
- Build privacy-friendly tools with no backend when one is not needed.
- Validate user data and explain problems clearly.
- Create dashboard UI with readable visual hierarchy.
- Package a project for GitHub, Vercel, and client demos.
