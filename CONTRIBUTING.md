# Contributing

Thanks for considering a contribution to InsightBoard CSV Dashboard.

## Local Setup

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm run lint
npm run build
```

## Project Boundaries

Please keep the starter simple and local-first:

- No backend, database, login, analytics, paid APIs, or secrets.
- No complex state management unless there is a clear need.
- Preserve CSV upload, demo data, validation warnings, dashboard charts, data table, and Markdown export.
- Keep the app deployable as a static Vite site on Vercel.

## Good First Contributions

- Improve CSV examples and docs.
- Add small accessibility improvements.
- Add focused validation edge cases.
- Add screenshots or demo assets.
- Polish responsive layout.

## Pull Request Notes

Include a short summary, screenshots for UI changes, and confirmation that lint/build pass.
